# pulsar-ph

PULSAR-ph, or **P**ersonal **U**ser-curated **L**iterature **S**tream for **A**strophysics **R**esearch, is an IOS app that organizes daily arXiv submissions into a personalized feed with gamified features to encourage daily logins and reading. Over time, PULSAR-ph learns the user's subject preferences by training a neural network on both explicit and implicit user feedback.
